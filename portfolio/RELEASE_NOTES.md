# Release Notes - Pennywise v1.0.0 🚀

**Release Date:** November 14, 2026
**Status:** Production Ready (Scope Freeze)

We are thrilled to announce the official v1.0.0 release of Pennywise! This version marks the completion of Phase 3, bringing a secure, accessible, and fully-tested digital banking experience.

## 🌟 Key Features
*   **Secure Transactions:** OTP and PIN-based transfer workflows.
*   **PWA & Offline Support:** Fully installable app with a custom offline fallback.
*   **Real-Time Notifications:** Database-driven alerts via Supabase WebSockets.
*   **Full RTL Localization:** Complete English/Urdu support with Nastaliq fonts.
*   **Financial Analytics:** Dynamic charts for tracking income and expenses.

## 🛠️ Engineering Achievements
*   **100 Lighthouse Accessibility Score** and **91 SEO Score**.
*   **90% Bundle Size Reduction** (594kB to 37kB via code-splitting).
*   **Automated E2E Testing:** 100% passing Playwright test suite.
*   **CI/CD Pipeline:** Automated GitHub Actions workflow for zero-downtime deployments.

## 🧊 Scope Freeze Notice
With v1.0.0, the core feature set is officially **frozen**. Future updates will focus strictly on bug fixes, security patches, performance optimizations, and maintenance. Any new major features will be planned for v2.0.0.
